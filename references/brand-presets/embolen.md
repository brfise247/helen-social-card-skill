## 预设块

```css
[data-brand="embolen"] {
  /* 材料：纸 */
  --paper:        #FAF6EC;   /* 米纸，整卡底 */
  --paper-soft:   #F2EADB;   /* 次级纸面 / 表头 */
  --paper-deep:   #EDE3D0;   /* 折角背面 / 纸影 */
  /* 材料：双色蓝墨（蓝墨为主，粉墨 / 绿墨只在强调） */
  --ink:          #193B6F;   /* 蓝墨，10.26:1，标题与正文 */
  --sea:          #4793D0;   /* 鲸鱼蓝，只做面积 / 线 / ≥64px 大字 */
  --sea-ink:      #2C6390;   /* 品牌蓝的小字替身，5.91:1 */
  --brand-ink:    #2C6390;   /* 同 --sea-ink，语义别名 */
  /* 材料：荧光笔 */
  --sun:          #ECB957;   /* 荧光黄，只做底，上面永远压 --ink（6.14:1） */
  /* 块面（只做底 / 块，不做字） */
  --sky:          #9AC9ED;   /* 浅腹蓝：照片衬底 / 描红格 / 表格底 */
  --pink:         #DA6997;   /* 泡泡粉，只做块 */
  --sprout:       #87AC52;   /* 新芽绿，只做块 */
  /* 小字与弱化文字 */
  --muted:        #55677C;   /* 页码 / 元信息，5.38:1 */
  --accent-pink:  #A33C64;   /* 粉墨小字 / 印章文字，5.74:1 */
  --accent-green: #4E6A2B;   /* 绿墨小字 / 完成态，5.69:1 */
}
```

`--sea` 的职责被压缩到最小：只染书脊、蓝区、1px 规则线与 ≥64px 大字。
不要把它扩散到正文、小字或细描边 —— 一旦扩散，「那块蓝 + 米纸」的物理身份就丢了。

## 使用规则

- **四个装订装置固定复用**：书脊（56px 通栏 `--sea`）、页脚线（1px）、错位荧光条、折角或页码。
- **荧光黄是工具，不是颜色**：只做底，上面永远压 `--ink`；不得用黄色做字、线、图标。
- **蓝不做小字**：`--sea` 对米纸 3.06:1，只给 ≥64px 大字 / 线 / 面积；小字改用 `--sea-ink`。
  蓝底反白只给 ≥64px 或 ≥22px 粗体。
- **块面不做字**：`--sky` / `--pink` / `--sprout` 只做底与块；要小字用 `--accent-pink` / `--accent-green`。
- **圆角一律 0px**：唯一例外是圆形印章与 logo 圆形模切贴纸。线一律 1px。
- **不用渐变 / 阴影 / 发光**；唯一允许的实影是照片插页「贴在纸上」的偏移影。
- **六个 OFL 字面固定**：Noto Serif SC 900（中文 display）/ Noto Sans SC（正文）/ Yozai（手写批注）/
  Literata（书名 / 页码）/ Andika（教学英文）/ Charis SIL（音标）。教学英文永远比中文大，单词字距为 0。
- 字体授权只用 `references/font-license-audit.md` 里核验过的 OFL 1.1 字库。

## 内容边界

- **不编造数据**：学员数字、课程效果、优惠、时效一律可核验；未确认的数字用 `.pending` 虚线待补框，
  **不预填示例数据**。印章只盖真实日期 / 真实完成状态。
- **不承诺效果**：不写「N 天开口」「N 天流利」这类承诺型标题；不编造学员案例。
- **不用 AI 儿童**：封面 / 首图 0 卡通儿童、0 吉祥物、0 AI 或图库的「假笑儿童照」。
- **真实照片只用已授权素材**，且只做「照片插页」（白色 16px 边框、微旋 −1.8°、偏移实影），
  不做满版人像封面；没有照片就整块删除，不留占位框。
- **封面 / 首图 0 logo**：品牌由装订（书脊 + 页脚 + 折角）承担；logo 只允许出现在 P08 收束页的
  96px 圆形出版者标记与页脚文字行。
- 描述真实家庭场景，不描述制作方法；把转化留给正文和评论区，不在封面加价格或「点击购买」。

## 与其他预设的关系

品牌固定为英博伦，本目录不再维护多租户色板（旧的多品牌 / 多租户预设已随本次品牌迁移移除）。
其他品牌需求按 `DESIGN.md` 的 token 结构另建预设，不要混用本预设之外的调色板与字体栈。
