# Greenbook Specs（公众号图片消息 / 小绿书 / 贴图号）

微信公众号「图片消息」的规格、裁切行为、版面配方与渲染 / 导出 / QA 规则。
「小绿书」是坊间叫法，2026 年微信把该功能升级后官方称「**贴图号**」，两个名字指同一个位。

- 设计真源：根目录 `DESIGN.md`（品牌层「翻到起毛边」+「平台应用 / 微信公众号」）。
- 模板：`assets/template-greenbook-card.html`（`W01` 首图 + `P01`–`P08` 内页，1080×1440 单文件种子）。
- 渲染验证：`node local-tests/rebrand-wechat/render.cjs`。
- 品牌预设：`references/brand-presets/embolen.md`。

## 平台规格

证据分级：**已核验** = 直接读到来源原文；**二手一致** = 多个独立二手来源数字一致，微信官方文档未直接公开。
凡标「二手一致」的，首次正式投放前请用一条真实发布自行复核。

| 项 | 值 | 证据 |
|---|---|---|
| 最佳比例 | 3:4，横滑浏览 | 已核验（横滑 + 3:4 展示比例） |
| 画布尺寸 | 1080 × 1440（备选 1242 × 1660） | 二手一致 |
| 图片张数 | 平台上限 20 张；本系统一套 6–9 张（封面 + 4–7 内页 + 收束） | 上限二手一致；6–9 张是内容节奏建议 |
| 标题 | ≤ 64 字 / 字符 | 二手一致 |
| 描述 | ≤ 1000 字（由 140 扩容而来） | 已核验（扩容事实） |
| 描述实操长度 | 200–300 字 | 二手一致（运营建议） |
| 话题标签 | 2–3 个精准标签 | 二手一致 |
| 消息列表封面 | ≥3 张时取前 3 张拼成 2.35:1 缩略条 | 二手一致 |
| 常读列表 | 首图裁切为 16:9 | 二手一致 |

### 本系统的交付口径

- **首图 `W01` 交付三张**：1080×1440（整图）、1080×608（16:9 裁切验证）、1080×459（2.35:1 裁切验证）。
  三张并排 **肉眼确认标题一字不缺**、英文行与册号完整、荧光条不断头。
- **内页页脚右文案**：`公众号图片消息 · 03 / 07`。这是格式示例（当前页 / 总张数），
  一套真实卡组导出前按实际张数重排；**不写「收藏」类平台互动话术**，写「今晚就能做」。
- **首图 0 logo**：品牌由书脊 + 页脚 + 荧光条 + 页码四个装订装置承担。
  logo 只允许出现在 `P08` 收束页的 96px 圆形出版者标记与页脚文字行。
- **真实照片只做「照片插页」**：白框、微旋、实影；只接受已授权的家庭 / 孩子照片。
  不用 AI 生成儿童，不用图库摆拍儿童照，不做满版人像。

## 裁切数学（本模板全部构图的起点）

### 16:9 常读列表

1080 × 9/16 = 607.5 → **608px**；垂直居中：(1440 − 608) / 2 = 416。
安全带 = **y 416 – 1024**。带外内容会被砍掉，所以带外只放可被砍掉的东西（手写批注 / 留白）。

### 2.35:1 三图缩略条

按 `DESIGN.md` 的口径：单图居中裁成 2.35:1，画布高 1080 / 2.35 = **459.57 → 交付 1080×459**；
垂直居中：(1440 − 459.57) / 2 = **490.2**，即上沿 **y490**、下沿 **y950**（取整到 460px 带高）。
**唯一安全带 = y 490 – 950**（16:9 ∩ 2.35:1 的交集）。

> 口径备注：平台「三图缩略条」实际是三张 3:4 并排，每格约 1:1.277，源图上下各只裁约 30px，
> 比 y490–950 宽松得多。本系统仍按更保守的 y490–950 验收——两种口径下带内内容都安全；
> 若平台规则更新，先复核本节的裁切带，再改模板。

**首图论点（标题 + 英文行 + 册号）必须完整落在 y490–950 内。** 做不到就重排，不要缩字。

### 前三张锁基线

前三张并排成 2.35:1 缩略条时要横读不跳：
页脚线固定 **y1288**、内页书脊底部页码同一位置；`W01` 的英文行 / 1px 线 / 册号按 `DESIGN.md`
的 y800 / y862 / y882 放置。模板把这几个基线写死在 CSS 里，改构图时不要动。

### 验证与导出

模板内置 `body[data-guides="on"]` 裁切参考层：画出 16:9 安全带线（y416 / y1024）、
2.35:1 裁切带线（y490 / y950）与标签，安全带底色为浅荧光黄。

1. 排版时改成 `on`：`<body data-guides="on">`。
2. 裁成 y416–1024 与 y490–950 两张验证图，肉眼确认论点完整。
3. **导出前必须改回 `<body data-guides="off">`**，否则红蓝参考线会印进成品。

## 配方表：`W01` + `P01`–`P08`

一套卡 6–9 页：`W01` 首图 + 4–7 张内页 + `P08` 收束。同一套里每页只承担一件事，
至少出现 5 种不同版面形状。内页配方与小红书 3:4 图文卡共用（见 `DESIGN.md`「Page Recipes」）。

| 配方 | 名字 | 用在哪 | 结构 / 硬约束 |
|---|---|---|---|
| **W01** | 首图 | 公众号图片消息第一张 | 蓝区 y0–520；英文书名行 Literata；中文标题两行 84–92px 落 y566–780；英文行 y800；1px 线 y862；册号 y882；**标题 / 英文行 / 册号全在 y490–950**；0 logo |
| **P01** | 一句 | 观点 / 转折 / 金句 | 宋体 96px 主句（≤4 行 × ≤9 字）压荧光条；页边一条 Yozai 竖排批注（≤12 字）；允许 ≥1/3 留白 |
| **P02** | 双声部 | 亲子共读现场 | 左右两栏 + 1px 中线：大人（Noto Sans SC 38px，短句、可执行）/ 孩子（Andika 56px + Yozai 手写原话）；全系统唯一「两个人」 |
| **P03** | 步骤 | 方法 / 共读流程 | 纵向 01–05 + 一条竖线；每步 ≤24 字；无 icon、无箭头装饰；侧边可挂 1 条手写批注 |
| **P04** | 对照 | 路线 / 方法对比 | 两栏表头色带（`--paper-soft`）+ 每栏 ≤3 行；只比 2 个对象；胜出项压荧光条；不用对勾 / 叉号图标 |
| **P05** | 词句 | 每周一词 / 句型 | Andika 单词 226px + 音标（Charis SIL）+ 中文注 36–44px + 例句 Andika 52px + 描红格 + 家长提示；**英文永远最大、字距为 0** |
| **P06** | 清单 | 今晚就能做 / 共读清单 | 宋体标题 72px + 6 行方格清单 + 2 个空行；页脚上方一行手写「做到 N 条就很好」 |
| **P07** | 记录 | 读书记录 / 成长记录 | 4 行记录表（读的书 / 新学的词 / 最喜欢的一页 / 他的一句话）+ 印章（真实日期）；**字段留空、不预填** |
| **P08** | 收束 | 末页 / 下一册预告 | 宋体 104px 两行 + 手写晚安句 + 96px 圆形出版者标记 + 下一册书名；**整套唯一允许出现 logo 的内页**；折角回归 |

建议页序：`W01` → `P01` / `P02` → `P05` / `P03` → `P06` / `P04` → `P07` → `P08`。
按素材删减时保留「一句 + 词句 + 清单 / 记录」三件，收束页必须在最后。

## 空状态与 `.pending`

- **没有照片** → 整块删掉 `.photo-insert`，不留占位框；不要拿插画或 AI 图占位。
- **数字 / 日期 / 学员数据未确认** → `.pending` 虚线待补框，**不编造、不预填示例数据**。
- **`P07` 记录页** → 4 行 `.val` 留空给真实填写；印章只在有真实日期时启用，模板不预盖。
- **`P08` 出版者标记** → 有品牌方 logo 文件时替换 `<img src="assets/logo-embolen.png">`；
  没有时保留模板里的临时字标，**不要自己重绘商标**。
- **标题超限** → 先改文案；`W01` 中文标题改不到 ≤3 行 × ≤9 字就换构图，绝不缩到 <84px。

## 渲染

沿用 `references/production-workflow.md` 的 Playwright 流程，本模板的硬要求：

- Playwright + 本机 Chrome；`deviceScaleFactor: 2` 渲染（2160×2880）后再 Lanczos 缩回 1080×1440。
- 字体走 CDN（Google Fonts + cn-fonts 的 Yozai），渲染前等 `document.fonts.ready` 并再留 1.5s。
- **打印 `document.fonts` 里 `status === 'loaded'` 的 family 自检**：六个面缺一个都算失败。
  离线 / CDN 不可达时改为自托管字体文件，**不要让它静默回退**——宋体 900 一旦退成系统宋体，
  成品只是「有点普通」，很难被发现。
- 按 `.board` 元素截图（1080×1440），不要整页截图：页外的 `.cap` 说明文字不进成品。

一条命令跑完字体自检、版面自检、W01 裁切断言与全部 PNG：

```bash
node local-tests/rebrand-wechat/render.cjs
```

产物在 `local-tests/rebrand-wechat/output/`：`w01.png` + `p01.png`–`p08.png`（1080×1440）、
`w01-guides.png`（裁切参考层）、`w01-1080x608.png`（16:9）、`w01-1080x459.png`（2.35:1）。

## 导出与命名

- 导出状态：`data-guides="off"`，sRGB PNG，1080×1440。
- 建议命名：`output/wechat-01-cover.png`、`wechat-02-<topic>.png` …；
  首图两张验证图 `output/wechat-01-cover-16x9.png`、`output/wechat-01-cover-235x1.png`。
- 投放前把卡面示例文案逐字替换成运营确认的内容；价格 / 课时 / 学员数据一律可核验。
